# 本地起始页

纯静态、零依赖的浏览器起始页，通过 `file://` 直接打开，无需本地服务器。
核心特性：本地 HTML 快捷方式（支持收纳夹与页面内管理）、多引擎搜索（联想词 + 历史）、必应每日壁纸、深浅色主题、一言。

## 一、启用（Chrome + New Tab Redirect）

1. 打开 New Tab Redirect 扩展的选项页，把跳转地址设为：
   ```
   file:///E:/Projects/BrowserStartPage/index.html
   ```
2. 如果新标签页显示空白：进入 `chrome://extensions` → New Tab Redirect → 打开 **「允许访问文件网址」**。

## 二、双视图交互（参考青柠）

搜索视图与应用（磁贴）视图互斥，时钟日期常驻：

- **空白处左键** → 搜索视图（自动聚焦输入框）
- **空白处右键** → 应用视图（磁贴列表，超高时内部滚动）
- `Esc` / `/` 也可从应用视图回到搜索

## 三、快捷方式管理（页面内直接操作）

- **添加**：点击磁贴末尾的虚线「+」，可选择添加快捷方式或收纳夹
- **编辑 / 删除**：右键磁贴
- **排序**：直接拖拽磁贴
- **放入收纳夹**：把普通磁贴拖到收纳夹磁贴上（悬停会高亮），松手即放入
- **移出收纳夹**：收纳夹内右键磁贴 → 「移出收纳夹」，回到顶层末尾
- **收纳夹**：点击打开弹层，夹内同样支持添加、右键、拖拽
- `url` 支持普通网址、`file:///` 绝对路径、项目内相对路径
- 图标：网站自动加载 favicon（结果有缓存，失败不闪烁），本地页面显示首字渐变徽标；也可手动填 emoji 或图片地址
- 超过 `gridMaxVisible`（默认 12）个会折叠进「展开」按钮

也可以直接编辑 [config.js](config.js) 的 `shortcuts` 数组（见下方「数据存储」）。

## 四、搜索

- 点击搜索框**左侧图标**弹出引擎菜单；`engines` 数组可增删，`{q}` 为关键词占位符
- 引擎图标使用 [Iconify](https://icon-sets.iconify.design)（`<iconify-icon>` Web Component，按需从 CDN 加载并本地缓存）。`icon` 字段填图标名，扁平单色、颜色自动跟随环境、大小统一。推荐统一用 Remix Icon（`ri:` 前缀）保持风格一致；新增引擎到 icon-sets.iconify.design 搜图标名即可，留空则显示名称首字
- 输入时显示百度联想词（↑↓ 键选择）
- 点击空搜索框显示**搜索历史**（单条删除 / 清空，最多 20 条）

## 五、快捷键

| 按键 | 功能 |
|------|------|
| `Alt+1` ~ `Alt+9` | 精确切换到第 N 个搜索引擎（输入中也可用） |
| `1` ~ `9` | 打开第 N 个磁贴（输入框无焦点时） |
| `/` | 聚焦搜索框 |
| `Esc` | 逐级关闭：菜单 → 弹层 → 应用视图 → 清空输入 → 失焦 |

## 六、设置面板（右下角齿轮）

语言（跟随浏览器 / 中文 / English，**底部一言来源随语言切换**：中文 = hitokoto 一言，英文 = 英文名言）、主题（跟随时间 19:00~7:00 深色 / 固定浅色 / 固定深色）、壁纸模式、壁纸压暗、联想词、搜索历史、一言、新标签页打开方式；以及**导出 config.js** 和 **恢复默认**。

## 七、数据存储与迁移

- [config.js](config.js) 是**基准配置**；页面内的所有修改（磁贴编辑、设置）保存在浏览器 localStorage 并优先生效
- **迁移浏览器 / 备份**：设置面板点「导出 config.js」→ 用下载的文件覆盖项目里的 config.js → 新浏览器直接用；旧浏览器可点「恢复默认」清除本地修改
- file:// 页面无法直接写本地文件，所以"改动落盘"必须经过导出这一步

## 八、壁纸

- **时效机制**：随机模式下壁纸随机选取，**当天内保持不变，每天凌晨 3 点自动更换**（刷新不换、长开标签页跨 3 点也会换）。实现方式是"日期+种子"生成稳定 URL（必应走 bing.biturl.top 按索引取近 8 天存档，随机图片走 picsum seed）
- **模式**（设置面板选择）：必应随机（默认）/ 随机图片 / 必应今日 / 自定义地址（https:// 或 file:///E:/… 本地图片）；在线源均为 4K UHD，失败逐级降级
- **换一张**：右下角图片按钮，立刻重抽一张，新抽到的同样保持到当天凌晨 3 点
- 所有直链都带日期参数，避免浏览器缓存旧重定向导致"刷新永远同一张"

## 九、file:// 环境的技术约束（改代码前必读）

| 限制 | 本项目的对策 |
|------|-------------|
| 不能 `fetch`/XHR 本地文件 | 配置写成 `config.js`（JS 变量）而不是 JSON |
| 不能写本地文件 | 页面内修改存 localStorage，经「导出」落盘 |
| 不能用 ES Module（`import`） | 全部用经典 `<script>` 标签 |
| 跨域 fetch 在线 JSON 会被拦 | 壁纸用图片直链；联想词用 JSONP；一言的接口带 `Access-Control-Allow-Origin: *` |
| `http(s)://` 页面不能跳转 `file://` | 起始页本身就是 file://，file→file 跳转是允许的 |
| favicon 无法转存 base64（画布跨域污染） | 只缓存「加载成功/失败」结果，图片本体依赖浏览器 HTTP 缓存 |

```

app.js                逻辑
config.js             ★ 基准配置
demo/hello.html       本地页面跳转演示
```
